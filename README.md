## 🚀 What I'm Building

### 🌐 Collabrio

A full-stack creator–brand collaboration platform designed to connect creators and businesses.

* Role-based access control & OAuth
* REST APIs and backend architecture
* Payment integration
* AWS S3 for file storage
* PostgreSQL
* Cron-based workflows
* Production-oriented deployment

### 🤖 Influencer Search Engine

An information-retrieval system for searching through **5,900+ creator profiles** using hybrid retrieval and LLM-based reranking.

* BM25 lexical retrieval
* Semantic search with embeddings
* Hybrid retrieval pipelines
* LLM reranking
* FAISS / vector search
* Sentence Transformers
* Retrieval evaluation using **Precision@10, Recall@10, MRR & NDCG@10**

The project improved **Precision@10 and Recall@10 by 49%**, achieving an **MRR of 0.9409** and **NDCG@10 of 0.7838**.
