- 🌐 Focused on connecting people across the globe for brand & influencer marketing
- 🧠 Backed by a hybrid RAG/IR search pipeline (FAISS + BM25 + SentenceTransformers) for finding the right match, fast
- 🚀 Currently a web app — and I'm actively looking to take it mobile
